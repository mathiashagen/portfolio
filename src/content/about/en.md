I'm a fullstack developer at LocalHost AS in Ålesund, Norway. Day to day I work on a single
product all the way from the database to the screen: .NET and RavenDB on the backend, React
and TypeScript on the frontend. I have a bachelor's degree in computer science from NTNU in
Ålesund.

## What I like working on

I like problems where it isn't enough that the code works, where I need to understand why it
works. A system that has to run for weeks without anyone watching it, a protocol that has to
be decoded bit by bit, or an interface that should feel fast even when the data behind it
isn't.

## Outside work

In my spare time I learn new languages and tools by building things that have to actually
run. [AIS-pipeline](/en/projects/ais-pipeline/) started as a way to learn modern C++ properly,
and now runs around the clock on a home server with Proxmox and Docker. This site was built
the same way, as a project to learn Astro.

## Technologies

- **Day to day:** C#/.NET, React, TypeScript, RavenDB
- **In my spare time:** C++20, Astro, Docker, Proxmox, SQLite
