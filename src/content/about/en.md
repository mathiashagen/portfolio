I'm a fullstack developer at LocalHost AS in Ålesund, Norway, working on the SaaS platform
Overviu with .NET and RavenDB on the backend and React and TypeScript on the frontend. I've
been on it since early in development, and one of the things I've built is an MCP server that
lets AI assistants pull data from the platform.

## How I got here

I started out as an apprentice computer electronics technician, running servers and networks
and handling support and customers. After the trade certificate I took a bachelor's in
computer engineering at NTNU in Ålesund, through the vocational route into engineering. The
operations years left me with a habit of thinking about what happens to code after it ships.

## What I like working on

I like work I have to understand properly before I can get it right, like systems that need
to run for weeks with nobody watching, or protocols where every bit matters.

## Outside work

In my spare time I learn new languages and tools by building things that have to stay up, not
just exercises. [AIS-pipeline](/en/projects/ais-pipeline/) started as a way to learn modern C++
properly, and now runs around the clock on my home server with Proxmox and Docker. I made this
site to learn Astro.

## Technologies

- **Day to day:** C#/.NET, React, TypeScript, RavenDB, Model Context Protocol
- **Operations:** Microsoft Azure, Windows Server, Linux, Proxmox, Docker
- **In my spare time:** C++20, Astro, SQLite
